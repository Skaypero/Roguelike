# Roguelike на Java + libGDX

Небольшой roguelike с полноэкранным режимом, выровненным интерфейсом и генерацией текстур во время запуска (без бинарных ассетов в репозитории).

## Что есть в игре

- Комнаты размером **40x40** клеток.
- Главное меню:
  - `1` — случайная генерация,
  - `2` — заранее подготовленные шаблоны комнат из `src/main/resources/maps`.
- В комнатах:
  - стены и двери,
  - несколько монстров,
  - несколько сундуков,
  - ловушек нет,
  - несколько стилей планировки (острова, коридоры, руины).
- Инвентарь с выбором предмета:
  - `Tab` / `Shift+Tab` — переключение,
  - выбранное оружие влияет на урон,
  - `Q` использует расходник.
- Текстуры генерируются в рантайме:
  - исходный размер тайла **64x64**,
  - масштаб клеток подстраивается под текущее разрешение экрана,
  - тема текстур зависит от координат комнаты.
- Игра запускается в fullscreen, карта и панель автоматически центрируются.

## Управление

- `W/A/S/D` или стрелки — движение
- `F` — удар по ближайшему монстру
- `E` — открыть ближайший сундук
- `Q` — использовать расходник
- `Esc` — вернуться в меню

## Запуск

```bash
mvn exec:java
```

## Тесты

```bash
mvn test
```
