# Roguelike (Java, desktop)

Небольшой roguelike как **оконное приложение** (не консоль):
- Герой стартует в комнате `(0,0)`.
- Из комнаты можно перейти в 4 стороны (север/восток/юг/запад).
- Комнаты генерируются случайно при первом посещении.
- В комнатах есть монстры и сундуки с предметами.
- У героя есть инвентарь, оружие повышает урон, расходники лечат.

## Управление

- `W/A/S/D` или стрелки — движение между комнатами
- `F` — атака монстра в комнате
- `E` — открыть сундук
- `Q` — использовать лечащий предмет

## Запуск

```bash
mvn exec:java
```

## Тесты

```bash
mvn test
```

## Что можно использовать дальше

Если захочется полноценный игровой фреймворк (карта, спрайты, анимации, сцены),
самая популярная Java-библиотека для 2D-игр — **libGDX**.
Этот проект можно использовать как основу логики и потом перенести рендер/ввод в libGDX.
